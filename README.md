# Sistema de Aprovação de Compras Corporativas

Projeto de hobby desenvolvido em .NET para simular o gerenciamento de solicitações de compras corporativas, incluindo fluxo de aprovação baseado em valor e níveis de responsabilidade, histórico de decisões e regras de negócio. O projeto será desenvolvido de forma incremental, explorando boas práticas de desenvolvimento backend, arquitetura, testes e Docker.
